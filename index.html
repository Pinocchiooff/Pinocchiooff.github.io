1. Fondamentaux des Drones

Principes Généraux

Qu'est-ce qu'un drone ? Un drone (ou UAV - Unmanned Aerial Vehicle) est un aéronef sans pilote à bord, contrôlé à distance ou de manière autonome.

Types de drones : Multirotor (quadcoptères, hexacoptères), avions fixes, hélicoptères, VTOL (décollage/atterrissage vertical)

Composants Essentiels

Moteurs et Hélices : Moteurs électriques brossless (BLDC) avec contrôleurs ESC (Electronic Speed Controller)

Batterie : LiPo (Lithium Polymère) haute densité énergétique pour l'autonomie en vol

Capteurs IMU : Accéléromètres, gyroscopes, magnétomètres pour la stabilité et l'orientation

Récepteur : Reçoit les commandes radio de la télécommande ou du sol

4. Essaims de Drones (Drone Swarms)

Concepts Fondamentaux

Qu'est-ce qu'un essaim de drones ?

Ensemble de drones autonomes travaillant ensemble de manière coordonnée, avec communication décentralisée et intelligence collective.

Applications des Essaims

  • Surveillance et reconnaissance de zones
  • Cartographie et relevés géographiques
  • Recherche et sauvetage
  • Intervention d'urgence
  • Inspection d'infrastructures étendues

Technologies d'Essaim

Communication Décentralisée

Protocoles mesh, ad-hoc networking, communication peer-to-peer entre agents sans point central.

Algorithmes de Coordination

Flocking, consensus distribué, formation control, path planning collaboratif.

Intelligence Collective

Agents autonomes prenant décisions locales menant à comportement global cohérent (stigmergie).

Projets et Documentation

GitHub — Drone Swarm

Projets open source consacrés aux essaims de drones et systèmes multi-drones.

https://github.com/topics/drone-swarm

DARPA Swarmanoid Challenge

Benchmark international pour essaims de robots miniaturisés et coordonnés.

Multi-Agent Path Finding (MAPF)

Techniques de planification de trajectoires pour plusieurs agents évitant collisions.

5. Pilotage et Contrôle

Modes de Pilotage

Télépilotage Manuel

Contrôle direct en temps réel via télécommande ou station sol. Tous les mouvements gérés par l'opérateur.

Modes Stabilisés

Altitude hold, attitude hold : l'autopilote stabilise le drone, opérateur contrôle vitesse/direction.

Pilotage Autonome

Missions programmées, waypoints, retour auto à la base, lancements/atterrissages automatiques.

Contrôleurs de Vol

Contrôleur d'Attitude

Boucles PID pour maintenir orientation (roll, pitch, yaw). Entrées : angles désirés, sorties : vitesses moteur.

Contrôleur de Position

Navigation vers waypoints. Utilise capteurs GPS, vision, inertie pour localisation et trajectoire.

Filtres Estimateurs

Kalman filter : fusionne données IMU, GPS, baromètre pour état optimal (position, vitesse, orientation).

6. Pilotage GPS et Navigation Autonome

Systèmes de Localisation

GPS (Global Positioning System)

Système américain de positionnement. Précision : 5-10 mètres en mode standard, meilleure avec DGPS/RTK.

GNSS (Global Navigation Satellite System)

Ensemble des systèmes : GPS (USA), GLONASS (Russie), Galileo (Europe), BeiDou (Chine).

RTK (Real-Time Kinematic)

Technique de correction différentielle. Précision centimétrique avec station base. Essentiel pour missions de précision.

Vision-Based Navigation

Caméra + optical flow pour localisation en indoor/zones sans GPS (vision monoculaire/stéréo).

Planification de Trajectoires

Waypoint Navigation

Définir liste de points GPS à visiter séquentiellement. Drone calcule trajectoires optimales.

Path Planning Algorithms

Dijkstra, A*, RRT (Rapidly-exploring Random Trees) pour générer chemins sans collisions.

Obstacle Avoidance

Détection en temps réel via lidar, radar, caméras. Recalcul de trajectoire à la volée.

Ressources Techniques

PX4 - Position Controller

Architecture de contrôle position/vitesse, fusion sensorielle, compensation du vent.

https://docs.px4.io/main/en/flight_controller/autopilot_architecture.html

RTK GPS Setup

Configuration stations base, communication radio, calibrage précision.

https://docs.px4.io/main/en/gps_compass/rtk_gps.html

7. Télémétrie et Capteurs

Données de Télémétrie

État de Vol

Position (lat, lon, alt), vitesse, attitude (roll, pitch, yaw), accélérations.

Santé du Système

Tension batterie, courant, température moteurs, état ESC, saturation capteurs.

Diagnostique et Erreurs

Codes d'erreur, avertissements, logs de vol pour débogage post-mission.

Capteurs Principaux

IMU (Inertial Measurement Unit)

Accéléromètres (3 axes), gyroscopes (3 axes), magnétomètre (compas). Fréquence : 500-1000 Hz.

Baromètre

Mesure pression atmosphérique → altitude. Essentiel pour altitude hold.

GPS/GNSS

Position globale, vitesse, heading. Fréquence : 1-10 Hz selon module.

Caméra

Vision pour détection d'objets, mapping, évitement d'obstacles, opérations terrain.

Lidar

Scan 3D de l'environnement. Distance 2D/3D pour navigation précise, mapping.

Capteurs Spécialisés

Infrarouge thermique, multispectral, radiométrie pour applications scientifiques/inspection.

Protocoles de Communication

MAVLink

Protocole standard industrie. Échange messages entre autopilote et station sol. Binaire, efficace, extensible.

https://mavlink.io/

QGroundControl

Station sol universelle. Telemetry en temps réel, planification missions, tuning paramètres.

http://qgroundcontrol.com/

Logging et Data Analysis

Enregistrement complet missions. Analyse post-vol : performance, anomalies, optimisation.

8. Programmation ROS (Robot Operating System)

Introduction à ROS

ROS Official

Framework open source pour robotique. Gestion capteurs, contrôleurs, planification, vision, simulation.

https://www.ros.org/

ROS 2

Évolution moderne de ROS. DDS middleware, sécurité renforcée, performance temps réel améliorée.

https://docs.ros.org/en/humble/

Architecture ROS

Noeuds (nodes), topics (pub/sub), services (RPC), actions (long-running tasks). Communication distribuée.

ROS pour Drones

MAVSDK - MAVLink SDK

Librairie ROS pour communicer avec autopilotes (PX4, Ardupilot). Contrôle haut-niveau, missions, accès télé.

Code source et exemples d'intégration avec PX4 et Ardupilot.

https://github.com/mavlink/MAVSDK

Packages ROS officiels pour contrôle PX4, simulation Gazebo, vision processing.

https://docs.px4.io/main/en/ros/ros1.html

Ardupilot ROS

Packages ROS pour Ardupilot, intégration mavproxy, navigation autonome.

https://ardupilot.org/dev/docs/ros.html

Modules Robotiques Clés

Navigation Stack

Planification trajectoires (move_base), costmaps locales/globales, évitement obstacles temps réel.

Vision (cv_bridge, image_transport)

Traitement images OpenCV intégré ROS. Object detection, SLAM visuel, reconnaissance.

rviz et rqt

Visualisation 3D temps réel, graphes topics/services, tunage paramètres dynamiques.

tf (Transform Framework)

Gestion coordonnées multiples frames (body, world, camera). Fusion sensorielle.

10. Réglementation Aérienne

Autorités Régulatrices

EASA (European Aviation Safety Agency)

Agence européenne sécurité aérienne. Règles UAV/drones, certifications, catégories opérations.

https://www.easa.europa.eu/en/domains/

EASA - Special Conditions UAV

Cadre légal drones, agréments opérateurs, zones d'exclusion, assurance responsabilité civile.

https://www.easa.europa.eu/en/easa-and-you/civil-drones-rpas

FAA (Federal Aviation Administration - USA)

Régulation américaine drones. Certificat Part 107, airspace restrictions, flight authorizations.

https://www.faa.gov/uas/

Catégories d'Opérations

Catégorie Ouvert

Vols simples à faible risque. Drones légers, basse altitude, zone contrôlée opérateur.

Catégorie Spécifique

Opérations complexes nécessitant agrément. Autorisations préalables, conditions spécifiques.

Catégorie Certifiée

Haute complexité/risque. Certification drone et opérateur, standards industriels stricts.
